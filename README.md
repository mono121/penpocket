# 筆記具コレクション

万年筆・ボールペン・シャープペンシルの収集記録。GitHub Pages + Jekyll。

## 1本追加する

`_pens/` に Markdown を1枚置くだけ。一覧・詳細ページ・統計はビルド時に自動生成される。

```yaml
---
title: 正式なモデル名
brand: brand-key       # _data/brands.yml のキー
# type: 万年筆 / ボールペン / ペンシル / パーフェクトペンシル / ローラーボール / 多機能ペン
# color: グリーン      # 色名
# nib: F               # 字幅・ペン先情報。不要なら省略
# line_width: 0.5      # 芯径・線幅（mm）。不明なら省略
# limited: 世界100本  # 限定数
# commemoration: 100周年記念
# accessories: [箱, 冊子]
# custom_fields:
#   - label: 識別ポイント
#     value: フラットトップ、目盛り0
# mechanism: 機構名    # 吸入式、ノック式など
# body: 軸・外装の素材や仕上げ
# ink_name: 使用中のインクまたは替芯
acquired: 2026         # 入手年。不明なら推定年を相談
# tags: [ヴィンテージ, 限定品]
---

特徴、状態、使用感、来歴などの公開用メモ。
```

最低限必要なのは `title`、`brand`、`type`、`acquired`。新しいブランドを足す場合は `_data/brands.yml` に表示名と国を追加する。

## ローカルで確認する

```bash
bundle install
bundle exec jekyll serve
# http://localhost:4000
```

## 公開する

1. GitHub に push
2. Settings → Pages → Source を `main` ブランチに設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 公開リポジトリに書かない情報

- 購入価格・購入店
- 完全なシリアル番号
- 譲渡元の個人名
- 撮影場所や自宅が特定できる記述

## 写真を足す場合

- 配信用に変換した画像だけをコミットする
- 推奨は長辺1200pxのWebPと、一覧用400pxサムネイル
- 位置情報などのEXIFを削除する
- Git LFSはGitHub Pagesの直接配信には使用しない


## 現在の登録件数

初回入力分を表記統一して **58点** 登録済み。`種類未確認` や `要確認` タグの項目は、写真などで後から確定できる。

## タグの運用ルール

タグは検索・集計に使う横断分類だけに限定します。モデル名、カラー、素材の固有名、確認待ち事項はタグにしません。1本につき原則3個以内です。

使用できるタグ：

- 限定性：`限定品`
- 年代・世代：`ヴィンテージ`、`初期型`、`最初期型`
- 素材・外観：`透明軸`、`木軸`

限定数は `limited`、記念内容は `commemoration`、素材は `body`、未確定情報は本文または `custom_fields` に記録します。`要確認`、`希少モデル`、`コレクター分類`などはタグに使用しません。
